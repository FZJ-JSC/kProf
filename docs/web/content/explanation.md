# Explanation

kprof separates project code, tests, build support, and documentation so that each concern has a clear place in the repository.

The C++ implementation lives under `src/cpp`, while tests are grouped by testing level under `tests`. CMake provides the build entry point and the BESA modules under `cmake/besa` supply the project build conventions.

The documentation follows the Diátaxis structure: tutorials teach through a guided path, how-to guides solve specific tasks, reference material records precise interfaces, and explanation pages describe design and background. API pages are generated by cpdocs and mounted at `reference/api` by ProperDocs.
